Explorer
________

Front ends for looking at a simulation: an interactive widget for Jupyter, and a terminal
application that either explores it interactively (``-i``) or draws one view and exits.
The core is importable with nothing but numpy; only the Jupyter front end needs
``pip install "fdsreader[notebook]"``.
